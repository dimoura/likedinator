# Likedinator

Pipeline de personalização de CV para vagas.

## Quando o usuário pedir para adaptar o CV
Sempre execute o pipeline completo na ordem:
agent-1 → agent-2 → agent-3

Nunca pule etapas. O output de cada agente é o input do próximo.

Gatilhos: "adapta meu CV", "tailor my CV", "nova vaga", "personaliza"
